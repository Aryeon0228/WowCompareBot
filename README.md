# WoW Compare Bot

와우 클래식 Warcraftlogs CSV 파일 2개를 비교해서 퍼포먼스 차이를 분석해주는 디스코드 봇입니다.

## 주요 기능

### 자동 역할 감지
CSV 파일의 컬럼을 분석해서 자동으로 역할을 판단합니다:
- **DPS** - "DPS" 컬럼 있음
- **탱커** - "DTPS" 컬럼 있음
- **힐러** - "HPS" 컬럼 있음

### 역할별 비교 지표

#### DPS 분석
- 총 DPS 차이
- 주요 스킬 시전 횟수(Casts) 비교
- 치명타율(Crit %) 차이
- DoT 스킬 Uptime % 비교
- 누락된 스킬 확인

#### 탱커 분석
- 총 받은 피해(DTPS) 비교
- Mitigated (피해 감소율) 비교
- Miss % (회피율) 비교
- 주요 피해 소스별 비교

#### 힐러 분석
- 총 HPS 비교
- Overheal % 비교
- 주요 힐 스킬 사용 빈도
- 치명타율 비교
